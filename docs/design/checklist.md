# UI 交付自检

交付前逐条回答，任一不过就重写：

1. 9 条硬禁用是否全部为「否」？（渐变 / 霓虹 / 玻璃 / 紫蓝 / 大圆角 / 多层阴影 / emoji / 假文案 / 落地页结构）
2. 颜色、间距、字号、圆角、阴影是否全部来自令牌？
3. 交互元素 8 态是否齐全？
4. 键盘 Tab / Shift+Tab / Esc 是否可用？弹层焦点是否被困住？
5. 正文对比度是否 ≥ 4.5:1？
6. `prefers-reduced-motion` 下是否没有动画？
7. 375px 窄屏是否可用，输入框和弹层是否被遮挡？
8. 计划卡和任务栏状态是否与真实执行一致？
9. `npm run ui:check` 是否 0 失败？`npm test` 是否全绿？
