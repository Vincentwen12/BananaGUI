# 文案与内容

## 规则

- 用用户的语言；中文界面不夹无意义英文。
- 先结论后解释；按钮写动作（「保存」「停止生成」），不写模糊的「确定」。
- 错误文案说明：发生了什么、为什么、下一步能做什么。
- 不写 Lorem ipsum、假数据、编造的性能数字。
- 不用 emoji 作为图标或状态；需要图形时用 SVG。
- 空状态给出一个明确动作，不只写「暂无数据」。
- 危险操作写清后果，并提供取消。

## 反例

```text
出错了。
```

## 正例

```text
保存失败：配置文件不可写。请检查 D:\BananaCLI-data 的权限，或设置 BANANA_HOME 后重试。
```

## 扫描器

`no-lorem`、`no-emoji`；错误文案质量为人工验收。

## 验收

用户能从错误信息知道下一步；按钮动词明确；无假数据。
