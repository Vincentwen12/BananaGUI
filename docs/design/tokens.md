# Banana 设计令牌

唯一令牌源：根目录 `design-tokens.json`。CSS 变量映射在 `src/ui/style.css` 的 `:root`。

## 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `bg` | `#f4f7fa` | 工作区背景（冷灰） |
| `panel` / `panel2` | `#ffffff` / `#eef2f6` | 面板层级 |
| `border` / `borderStrong` | `rgba(0,0,0,.09)` / `.18` | 边框与分隔 |
| `text` / `text2` / `text3` | `#1a1a1a` / `#5a6472` / `#8a94a3` | 文字层级 |
| `accent` / `accentInk` | `#ffc400` / `#6f5200` | 记号笔黄，只做重点 |
| `onAccent` | `#241c00` | 黄底上的文字 |
| `danger` / `success` | `#c9564a` / `#2f7d50` | 语义色 |

规则：黄色不写字；黄底一律用深褐 `#241c00`；需要黄字时用 `#6f5200`。

## 圆角

`none` 0、`sm` 4、`md` 6、`lg` 6。矩形表面 ≤ 6px；胶囊/开关/滚动条/头像可用 `99px` / `999px` / `50%`。

## 阴影

全部 `none`。面板靠 1px 边框和背景色分层，不靠阴影。

## 间距

`4 / 8 / 12 / 16 / 24 / 32 / 40 / 48`。CSS 变量：`--space-1..8`。

## 字号

`10 / 12 / 13 / 15 / 20 / 28`。正文 13px，辅助 12px，可复制的值用等宽。

## 强制规则

- 令牌文件之外不得出现 `#hex`、`rgb()`、`hsl()`。
- 不允许 `border-radius: 16px` 这类裸值；用 `var(--radius-*)`。
- 项目存在 `design-tokens.json` 时，`ui_audit` 会把令牌外硬编码颜色视为失败。
- 颜色对比度由令牌组合保证；新增颜色必须同时提供深色主题值。
