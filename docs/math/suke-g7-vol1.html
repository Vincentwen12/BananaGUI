第 1 章数学与我们同行

全册的“方法启蒙”章：不考难题，但决定了后面五章怎么学。

第 1 章

数学与我们同行

主线：从生活现象出发 → 观察、实验 → 归纳、猜想 → 用数学语言表达 → 验证。

核心知识点

要点具体内容
生活 数学数学源于生活：测量、估计、图案、统计、编码（身份证号、条形码）中的数学；用数学解决实际问题的一般过程：实际问题 → 数学问题 → 求解 → 检验 → 回到实际。
活动 思考数学活动的基本方法：动手操作（折、剪、拼、量）、画图实验、数据记录、类比与归纳。
观察与实验观察要有顺序、有目的；实验可以“先猜后验”，用反例否定猜想。
归纳与猜想从特殊到一般：找出图形数、数列的变化规律，用含 n 的代数式表示（这一思路在第 3 章“规律探索”中正式使用）。

易错提醒

  • “看起来相等”不等于“相等”：凭眼睛判断长度、面积、角度常常出错，必须测量或推理。
  • 归纳出的规律要检验：只验证前 2 个数就下结论，容易出错；至少多验证几组。
  • 结论要写完整：说“面积变大”不如说“边长每增加 1 cm，面积增加多少”，能量化才叫数学。

典型例题

例把一张长方形纸片对折 1 次得 2 层，对折 2 次得 4 层……对折 n 次得多少层？对折 10 次大约多少层？

看解答

每对折一次层数翻倍，对折 n 次得 2n 层。对折 10 次为 210 = 1024 层。

第 2 章有理数

全册计算的地基。这一章的符号错误会一路带到方程和整式，必须练到“稳”。

第 2 章

有理数

结构：数的扩充（为什么要有负数）→ 有理数的表示（数轴）→ 有理数的“两把尺子”（相反数、绝对值）→ 四则运算与乘方。

一、数的分类

分类方式结果
按定义 有理数 = 整数（正整数、0、负整数）+ 分数（正分数、负分数）；有限小数和无限循环小数都可写成分数，所以也是有理数。
按符号 有理数 = 正有理数（正整数、正分数）+ 0 + 负有理数（负整数、负分数）。
无理数 无限不循环小数，如 π、0.1010010001…；它不是有理数，本章只需识别，不必运算。

二、数轴、相反数、绝对值

概念要点
数轴规定了原点、正方向、单位长度的直线（三要素缺一不可）。任何一个有理数都可以用数轴上的一个点表示，但数轴上的点不都是有理数。
相反数只有符号不同的两个数互为相反数，a 的相反数是 −a；0 的相反数是 0。几何意义：关于原点对称。若 a、b 互为相反数，则 a + b = 0。
绝对值数轴上表示数 a 的点到原点的距离，记作 |a|。必然有 |a| ≥ 0；
|a| = a（a ≥ 0），|a| = −a（a ≤ 0）。
比大小数轴上右边的数总比左边的大：正数 > 0 > 负数；两个负数比较，绝对值大的反而小。

三、四则运算与乘方

运算法则
加法同号相加：取相同的符号，绝对值相加。异号相加：取绝对值较大的加数的符号，用较大绝对值减去较小绝对值。互为相反数相加得 0；任何数加 0 仍是它本身。
减法减去一个数，等于加上这个数的相反数：a − b = a + (−b)。
乘法两数相乘，同号得正、异号得负，绝对值相乘；任何数乘 0 得 0。多个不为 0 的数相乘：负因数有奇数个则积为负，偶数个则为正。
除法除以一个不为 0 的数，等于乘这个数的倒数：a ÷ b = a × 1/b（b ≠ 0）。两数相除，同号得正、异号得负。
乘方求 n 个相同因数的积的运算。an 中 a 是底数、n 是指数、结果叫幂。正数的任何次幂都是正数；负数的奇次幂是负、偶次幂是正；0 的正整数次幂为 0。
混合运算顺序：先乘方，再乘除，最后加减；同级运算从左到右；有括号先算括号里的（小括号 → 中括号 → 大括号）。能用法算律（交换律、结合律、分配律）简算时优先用。

四、常见“数”的小结论

  • 最小的正整数是 1，最大的负整数是 −1，绝对值最小的数是 0。
  • 相反数等于它本身的数是 0；倒数等于它本身的数是 1 和 −1；平方等于它本身的数是 0 和 1；立方等于它本身的数是 0、1、−1。
  • 若 |a| = |b|，则 a = b 或 a = −b；若 |a| + |b| = 0，则 a = b = 0。

易错提醒

  • −a 不一定是负数。当 a ≤ 0 时，−a 是正数或 0。判断符号要看字母本身的取值。
  • (−3)2 与 −32 完全不同：前者是 (−3)×(−3) = 9，后者是 −(3×3) = −9。指数管到谁，看括号。
  • “减负”变“加正”：3 − (−5) = 3 + 5 = 8，别算成 −2。
  • 分配律漏乘：−2(x − 3) = −2x + 6，括号里每项都要乘，符号跟着走。
  • 绝对值化简先看符号：|a − 3| 在 a < 3 时等于 3 − a，不是 a − 3。
  • 0 不能作除数，0 没有倒数。
  • 科学记数法（a × 10n，1 ≤ |a| < 10）在不同修订版中出现的册次不同，以教材为准；若本册已学，注意 n 的确定方法（整数位数减 1）。

典型例题

例 1计算：−22 + (−3)2 × (1/3 − 1/2) ÷ (−1/6)

看解答

−22 = −4；1/3 − 1/2 = −1/6；(−3)2 = 9。
原式 = −4 + 9 × (−1/6) ÷ (−1/6) = −4 + 9 × (−1/6) × (−6) = −4 + 9 = 5。
注意 9 × (−1/6) = −3/2，再除以 −1/6 得 9 —— 同级运算从左到右，不能先算后面的除法。

例 2已知 |a| = 3，|b| = 2，且 a < b，求 a + b 的值。

看解答

a = ±3，b = ±2。由 a < b 排除掉 a = 3 的两种情况，剩：
a = −3，b = 2 → a + b = −1；a = −3，b = −2 → a + b = −5。
所以 a + b = −1 或 −5（两个答案，不能漏）。

例 3计算：(−1/2 + 2/3 − 3/4) × (−24)

看解答

用分配律：(−1/2)×(−24) + (2/3)×(−24) + (−3/4)×(−24) = 12 − 16 + 18 = 14。
直接通分也能做，但分配律更快，且要注意每一项都带括号、符号一并乘。

第 3 章代数式

从“算数”走向“算式”。核心只有两件事：会表示、会化简。

第 3 章

代数式

主线：用字母表示数 → 列代数式 → 求代数式的值 → 整式（单项式 + 多项式）→ 合并同类项与去括号。

一、用字母表示数与书写规范

情形规范写法
数与字母、字母与字母相乘乘号省略或写成“·”：a × b 写作 ab；2 × a 写作 2a
系数是 1 或 −11·a 写作 a；−1·a 写作 −a
带分数与字母相乘化为假分数：1½ × a 写作 (3/2)a，不能写成 1½a
除法写成分数形式：a ÷ b 写作 a/b
带单位和差形式要加括号：(a + b) 元；积商形式可省：(ab) 元或 ab 元

二、整式的相关概念

概念定义与要点
代数式用运算符号（加、减、乘、除、乘方）把数和表示数的字母连接起来的式子，单独一个数或一个字母也是代数式。含等号、不等号的不叫代数式。
单项式数与字母的积；单独一个数或字母也是单项式。系数包含前面的符号；次数 = 所有字母的指数之和（1/x 不是单项式）。
多项式几个单项式的和。每个单项式叫项，不含字母的项叫常数项；次数 = 次数最高的项的次数。
整式单项式和多项式统称整式。
同类项所含字母相同，并且相同字母的指数也相同。与系数无关，与字母排列顺序无关（2x²y 与 −yx² 是同类项）。

三、两条运算规则

  • 合并同类项：系数相加，所得结果作为系数，字母和字母的指数不变。3x² − 8x² = (3 − 8)x² = −5x²。
  • 去括号：括号前是“+”，去掉括号后各项符号都不变；括号前是“−”，去掉括号后各项都改变符号。多层括号由内向外，或由外向内（外括号前的符号要乘到内层每一项）。
  • 整式的加减 = 去括号 + 合并同类项，结果通常按字母次数从高到低（降幂）排列。
  • 求代数式的值：先化简再代入；能整体代入时不要拆（如已知 a − 2b = 3，求 5 − 2a + 4b）。

易错提醒

  • 系数别丢符号：−3x²y 的系数是 −3，次数是 3。
  • 多项式次数看“最高次项”，不看项数；常数项要连符号一起说。
  • 2x 与 2x² 不是同类项；3ab 与 3ac 也不是（字母不同）。
  • 去括号别只变第一项：−(2a − 3b + 1) = −2a + 3b − 1。
  • “合并”不要动指数：x² + x² = 2x²，不是 2x⁴。
  • 写结果别留括号：最后要化到最简，如 2(x − 1) − (x − 3) 应写成 x + 1。

典型例题

例 1化简：3(2x² − xy) − 2(3x² + xy − 1)

看解答

去括号：6x² − 3xy − 6x² − 2xy + 2；合并同类项：x² 项抵消，xy 项为 −5xy。
结果：−5xy + 2。

例 2已知 a − 2b = 3，求 5 − 2a + 4b 的值。

看解答

整体代入：5 − 2a + 4b = 5 − 2(a − 2b) = 5 − 2 × 3 = −1。
看到“−2a + 4b”，先提取 −2 凑出已知式，是这一章最常用的技巧。

例 3用棋子摆三角形：第 1 个用 3 枚，第 2 个用 6 枚，第 3 个用 9 枚……第 n 个用多少枚？第 20 个呢？

看解答

每增加一层就多 3 枚，是 3 的倍数：第 n 个用 3n 枚；n = 20 时为 60 枚。
规律探索三步：写出前几个数 → 找每次的增量 → 用含 n 的式子表示并回代检验。

第 4 章一元一次方程

全册的重点与难点，也是初中“建模”的起点：把文字变成方程，再解回来。

第 4 章

一元一次方程

主线：什么是方程 → 等式性质（解方程的合法依据）→ 五步解法 → 列方程解应用题。

一、基本概念

概念要点
方程含有未知数的等式。
方程的解使方程左右两边相等的未知数的值；只含一个未知数的方程的解也叫根。
解方程求方程解的过程（是过程，不是结果）。
一元一次方程只含一个未知数，未知数的次数都是 1，且等号两边都是整式。一般形式 ax + b = 0（a ≠ 0）。
等式性质 1等式两边加（或减）同一个数（或式），结果仍相等。
等式性质 2等式两边乘同一个数，或除以同一个不为 0 的数，结果仍相等。

二、解一元一次方程五步

步骤做法依据
1. 去分母两边同乘各分母的最小公倍数，不含分母的项也要乘；分子是多项式时先加括号。等式性质 2
2. 去括号按去括号法则，注意括号前是“−”时逐项变号。分配律
3. 移项把含未知数的项移到一边、常数项移到另一边，移项必须变号。等式性质 1
4. 合并同类项化为 ax = b 的形式。合并同类项
5. 系数化为 1两边同除以 a（a ≠ 0），得 x = b/a。等式性质 2

解完养成习惯：把解代回原方程口头检验一遍。

三、列方程解应用题

  1. 审：读题，圈出已知量、未知量、关键语句（“是……的几倍”“比……多/少”“相等”）。
  2. 设：设未知数并写清单位（直接设或间接设）。
  3. 找：找等量关系——这是整道题的核心。
  4. 列：把等量关系翻译成方程。
  5. 解：按五步求解。
  6. 验：既要检验方程的解，也要检验是否符合实际意义（人数不能是小数、时间不能为负）。
常见类型核心等量关系
行程路程 = 速度 × 时间。相遇：两者路程和 = 总路程；追及：路程差 = 初始距离；顺水 v顺 = v船 + v水，逆水 v逆 = v船 − v水。
工程工作量 = 工作效率 × 工作时间；常把总工作量设为 1，两队合作效率相加。
销售利润 = 售价 − 进价；利润率 = 利润 ÷ 进价 × 100%；打折售价 = 标价 × 折扣 ÷ 10。
配套按“配套比例”列等式（如 1 个桌面配 4 条腿）。
数字两位数 = 10 × 十位数字 + 个位数字；换位后重新表示。
年龄两人年龄差始终不变，n 年后每人都加 n。
比赛积分总场数 = 胜 + 平 + 负；总积分 = 各场得分之和。

易错提醒

  • 去分母漏乘：两边同乘公分母时，不含分母的项（如常数 1）也必须乘。
  • 分子是多项式不加括号：去分母后 (x − 1)/2 应变成 (x − 1)，否则符号全错。
  • 移项不变号：从等号一边搬到另一边，符号必须改变；只有“移”才变号，同一个数在一边内换位置不变号。
  • 系数化为 1 时符号丢掉：−3x = 6 得 x = −2，别写成 2。
  • 乱用性质 2：两边同除以的必须是同一个不为 0 的数；含有未知数的式子不能随便除。
  • 答案不合实际：人数、件数为整数，速度、长度为正，算出来先回头检查。

典型例题

例 1解方程：(x − 1)/2 − (2x + 1)/3 = 1

看解答

去分母（两边同乘 6）：3(x − 1) − 2(2x + 1) = 6
去括号：3x − 3 − 4x − 2 = 6
合并：−x − 5 = 6；移项：−x = 11；系数化为 1：x = −11。
检验：左边 = (−12)/2 − (−21)/3 = −6 + 7 = 1 ✓

例 2某商品进价 200 元，标价 300 元，若要求售出后利润率达到 5%，应打几折？

看解答

设打 x 折，则售价 = 300 × x/10 = 30x（元）。
利润 = 售价 − 进价 = 30x − 200，又利润 = 200 × 5% = 10，
所以 30x − 200 = 10，解得 x = 7。答：打七折。

例 3一项工程甲队单独做需 12 天，乙队单独做需 18 天。甲先做 3 天后乙加入，还需几天完成？

看解答

设总工作量为 1，甲效率 1/12，乙效率 1/18，再合作 x 天。
3 × 1/12 + x(1/12 + 1/18) = 1 → 1/4 + x × 5/36 = 1 → x × 5/36 = 3/4 → x = 27/5 = 5.4 天。
（若题目要求整天数，需说明“约 6 天”并解释取整的实际含义。）

第 5 章走进图形世界

从立体到平面、从平面到立体：画图与想象能力章，考点集中在展开图和三视图。

第 5 章

走进图形世界

主线：认识立体图形 → 图形的运动与生成 → 展开与折叠 → 三视图。

一、常见的几何体

类别说明
柱体圆柱（两底面是平面圆、侧面是曲面）、棱柱（两底面是全等多边形、侧面都是长方形）。
锥体圆锥（底面圆、侧面曲面、有顶点）、棱锥（底面多边形、侧面都是三角形）。
球体只有曲面，没有顶点和棱。
面、棱、顶点n 棱柱：面 n + 2 个，棱 3n 条，顶点 2n 个；n 棱锥：面 n + 1 个，棱 2n 条，顶点 n + 1 个。

二、图形的运动与生成

  • 三种基本运动：平移（方向、距离）、旋转（中心、角度）、翻折（沿一条直线，得到轴对称关系）。
  • 点动成线，线动成面，面动成体：长方形绕一边旋转一周得圆柱，直角三角形绕一条直角边旋转一周得圆锥，半圆绕直径旋转一周得球。
  • 面与面相交成线，线与线相交成点。

三、展开与折叠

  • 正方体表面展开图共 11 种：1-4-1 型 6 种、2-3-1 型 3 种、2-2-2 型 1 种、3-3 型 1 种。
  • 判断口诀：“一线不过四，田凹应弃之”——一条直线上最多 4 个正方形；出现“田”字或“凹”字形一定不能折成正方体。
  • 找相对面：在展开图中同一行（列）隔一个的两个面是相对面；“Z”字形两端的两面也是相对面。
  • 圆柱侧面展开是长方形（长 = 底面周长，宽 = 高）；圆锥侧面展开是扇形。

四、三视图

视图观察方向反映的量
主视图从正面看长与高
左视图从左面看宽与高
俯视图从上面看长与宽

规律：主俯长对正，主左高平齐，俯左宽相等。画三视图时，看得见的轮廓线画实线，看不见的画虚线。

易错提醒

  • 棱柱与圆柱别混：棱柱侧面是长方形（平面），圆柱侧面是曲面。
  • “展开图”不等于“随便画 6 个正方形”：必须能折成封闭正方体，注意口诀排除法。
  • 左视图方向搞反：左视图是从左往右看，得到的图形在纸上放在主视图右边。
  • 俯视图画成底面积：俯视图是平面图形，只表示轮廓与位置，不是立体图。
  • 由三视图数小立方体个数：俯视图上的数字表示该位置叠了几层，最多/最少问题要分别讨论。

典型例题

例 1一个棱柱共有 12 个顶点，它是几棱柱？有几个面、几条棱？

看解答

n 棱柱顶点数 2n = 12，得 n = 6，是六棱柱。
面数 = 6 + 2 = 8 个，棱数 = 3 × 6 = 18 条。

例 2将一个长 6 cm、宽 4 cm 的长方形绕它的一条长边旋转一周，得到的几何体是什么？体积是多少（π 取 3.14）？

看解答

绕长边旋转，得到底面半径 4 cm、高 6 cm 的圆柱。
V = πr²h = 3.14 × 16 × 6 = 301.44 cm³。
（体积公式属于后续学期内容，这里能说出“圆柱”并描述底面与高即可。）

第 6 章

平面图形的认识（一）

主线：线段、射线、直线 → 角 → 余角、补角、对顶角 → 平行 → 垂直。

一、线段、射线、直线

名称端点可否度量表示方法基本事实
直线0 个不能直线 AB（或直线 BA），也可用一个小写字母两点确定一条直线
射线1 个不能射线 OA（端点字母必须写在前面）—
线段2 个能线段 AB（或线段 BA）两点之间，线段最短
  • 两点之间的距离：连接两点的线段的长度（是一个数值，不是线段本身）。
  • 线段的中点：点 M 在线段 AB 上且 AM = MB，则 AM = MB = ½AB，AB = 2AM。
  • 线段的和差与比较：可用度量法或叠合法；线段上有 n 个点时，线段条数为 n(n−1)/2。

二、角

要点内容
表示方法三个大写字母（顶点字母在中间，如 ∠AOB）；顶点处只有一个角时可用顶点字母（∠O）；也可用数字或希腊字母（∠1、∠α）。
单位换算1° = 60′，1′ = 60″（六十进制）。例：32.5° = 32°30′；45°15′36″ = 45.26°。
分类锐角（0° < α < 90°）、直角（90°）、钝角（90° < α < 180°）、平角（180°）、周角（360°）。
角平分线从角的顶点出发，把角分成两个相等角的射线：∠AOC = ∠BOC = ½∠AOB。
余角两角之和为 90°，互为余角（互余）。同角或等角的余角相等。
补角两角之和为 180°，互为补角（互补）。同角或等角的补角相等。
对顶角两条直线相交形成的、有公共顶点且两边互为反向延长线的两个角，对顶角相等。

常用关系：一个角为 x，则它的余角为 90° − x，补角为 180° − x；同角的补角比余角大 90°。

三、平行与垂直

概念要点
平行同一平面内不相交的两条直线叫平行线，记作 a ∥ b。平行公理：经过直线外一点，有且只有一条直线与这条直线平行。推论：如果两条直线都与第三条直线平行，那么这两条直线也互相平行。
垂直两条直线相交成直角时互相垂直，记作 a ⊥ b，交点叫垂足。垂线的唯一性：在同一平面内，过一点有且只有一条直线与已知直线垂直。
垂线段从直线外一点向直线作垂线，这点与垂足之间的线段叫垂线段；垂线段最短。
点到直线的距离直线外一点到这条直线的垂线段的长度（是数值）。

易错提醒

  • “距离”是长度，不是线段：回答“点 A 到直线 l 的距离是 3 cm”，不能说“是垂线段 PD”。
  • 射线表示顺序不能颠倒：射线 OA 与射线 AO 不是同一条。
  • 度分秒是六十进制：0.5° = 30′，不是 50′；计算时先化成同单位再加减，借位按 60。
  • 余角、补角是“两角关系”：必须成对出现，单个角不能说“是余角”。
  • 对顶角要“两边互为反向延长线”：只是顶点相同、看起来相等，不算对顶角。
  • 平行、垂直都在“同一平面内”前提下讨论。
  • 书写要有依据：写“因为 ∠1 + ∠2 = 90°，所以 ∠1 与 ∠2 互余”，而不是只写结论。

典型例题

例 1一个角的补角比它的余角的 2 倍还多 30°，求这个角。

看解答

设这个角为 x°，则补角 180 − x，余角 90 − x。
180 − x = 2(90 − x) + 30
180 − x = 180 − 2x + 30 → −x + 2x = 30 → x = 30。
答：这个角是 30°。检验：补角 150°，余角 60°，2 × 60 + 30 = 150 ✓

例 2线段 AB = 10 cm，点 C 在 AB 上，M、N 分别是 AC、BC 的中点，求 MN 的长。

看解答

MN = MC + CN = ½AC + ½BC = ½(AC + BC) = ½AB = 5 cm。
结论：不管 C 在 AB 上什么位置，MN 恒为 AB 的一半——这就是“用式子代替图形”的好处。

例 3已知 ∠AOB = 80°，OC 平分 ∠AOB，OD 平分 ∠BOC，求 ∠AOD。

看解答

OC 平分 ∠AOB → ∠BOC = 40°；OD 平分 ∠BOC → ∠BOD = 20°。
∠AOD = ∠AOB − ∠BOD = 80° − 20° = 60°。

三步

从“会算”到“会想”

第一步：把计算练成条件反射（第 2、3 章）

  • 先做 20 道纯解方程（含分母、含括号、含小数系数），要求步骤写全、检验必做。

  • 整理一张“等量关系卡片”，只写关系不写答案，考前默写。
