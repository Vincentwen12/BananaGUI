## 中文

### 范围

本仓库的大部分代码、测试和文档由 AI 编程助手生成，包括：

- `src/` 下的 agent、provider、tools、server、CLI、UI 代码
- `gui/` 下的启动器、Electron 壳和同步界面
- `test/` 下的测试和 fixtures
- `docs/`、README 和发布说明

维护者进行了人工审查、测试、修复和发布检查，但这不是“完全人工审计”的代码库。

### 使用过的工具

- AI 编程助手（DeepSeek / OpenAI 兼容模型等）
- 人工编辑、代码审查、测试和发布脚本

不公开任何 API Key、账号凭据或私有环境信息。

### 人工做了什么

- 阅读关键路径代码，修正明显错误和不一致。
- 运行 `npm run typecheck`、`npm test`、`npm run build`、`npm run eval`、`npm run ui:check`、`node test/pack.test.mjs`。
- 补充回归测试，修复测试暴露的问题。
- 检查配置、权限、项目信任和密钥处理。
- 维护版本、README、变更记录和发布流程。

### 没有做什么

- 没有完整的第三方安全审计或渗透测试。
- 没有对所有依赖做供应链审计。
- 没有对每个平台做完整的真机矩阵验证。
- 没有保证“无漏洞”或“生产可直接使用”。

### 如何验证

```bash
npm install
npm run typecheck
npm test
npm run build
npm run eval
npm run ui:check
node test/pack.test.mjs
```

真实模型评测、A/B 和性能数字需要本地 API Key，仓库不会伪造这些结果。

### 安全提示

BananaCLI 可以：

- 读写工作区文件；
- 执行 shell 命令；
- 加载插件（全局自动，项目插件需信任）；
- 访问网络；
- 保存 API Key 到 `~/.banana/config.json`。

使用前请阅读权限模型和项目信任机制。不要把不可信仓库直接交给 agent 执行，不要把 API Key 提交到仓库。

## English

### Scope

Most code, tests, and documentation in this repository were generated by AI coding assistants, including:

- `src/` agent, providers, tools, server, CLI, and UI code
- `gui/` launchers, Electron shell, and synced UI
- `test/` tests and fixtures
- `docs/`, README, and release notes

The maintainer performed human review, testing, fixes, and release checks, but this is **not** a fully human-audited codebase.

### Tools used

- AI coding assistants (DeepSeek / OpenAI-compatible models, etc.)
- Human editing, code review, testing, and release scripts

No API keys, account credentials, or private environment data are published.

### What humans did

- Reviewed critical paths and fixed obvious errors or inconsistencies.
- Ran `npm run typecheck`, `npm test`, `npm run build`, `npm run eval`, `npm run ui:check`, and `node test/pack.test.mjs`.
- Added regression tests and fixed issues exposed by tests.
- Checked configuration, permissions, project trust, and secret handling.
- Maintained versions, README, changelog, and release flow.

### What was not done

- No full third-party security audit or penetration test.
- No complete supply-chain audit of every dependency.
- No full real-device matrix on every platform.
- No guarantee of “no vulnerabilities” or “production-ready without review”.

### How to verify

```bash
npm install
npm run typecheck
npm test
npm run build
npm run eval
npm run ui:check
node test/pack.test.mjs
```

Real-model evaluation, A/B, and performance numbers require a local API key; the repository does not fabricate those results.

### Security notes

BananaCLI can:

- read and write workspace files;
- execute shell commands;
- load plugins (global automatic, project plugins require trust);
- access the network;
- store API keys in `~/.banana/config.json`.

Read the permission model and project trust mechanism before use. Do not hand untrusted repositories to the agent, and do not commit API keys.
